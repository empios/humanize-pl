# AI-generated legal benchmark texts

Ten folder zawiera syntetyczne teksty prawnicze stylizowane na robocze teksty wygenerowane przez AI.
Służą do benchmarków `humanize-pl` w trybach `basic`, `nlp` i `hybrid`.

Założenia:
- teksty są fikcyjne i nie stanowią porady prawnej;
- zawierają celowo powtarzalne ramy typu `warto wskazać`, `istotne znaczenie`, `szczególną rolę`;
- zawierają elementy, których silnik nie powinien naruszać: kwoty, daty, artykuły, paragrafy, cytaty, strony, terminy i konstrukcje normatywne;
- są przeznaczone do oceny kontroli/redakcji tekstów AI na język prawniczy, nie do testowania zgodności merytorycznej z aktualnym prawem.
